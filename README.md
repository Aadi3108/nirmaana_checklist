# Nirmaana Endpoint Checklist

Open `index.html` in a modern browser. No build step or dependencies are required.

Includes:
- Today, weekly, 13-week roadmap, all tasks, people and product views
- 56 seeded tasks for the three-person team
- Owner, status, priority, deadline, dependency and acceptance criteria
- Editable/addable tasks
- Search and filters
- Local browser persistence
- JSON import/export
- Latest-source-of-truth context
- Nirmaana MVP compliance/architecture constraints from the uploaded PRD

The app is intentionally minimal and local-first so it can be opened immediately and edited without a backend.
